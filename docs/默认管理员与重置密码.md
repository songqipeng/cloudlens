# 默认管理员与重置密码

## 默认账号（首次部署或已执行重置后）

若你已通过下方「重置管理员密码」执行过重置，或曾用该密码创建过管理员，可使用：

| 项目 | 值 |
|------|-----|
| **用户名** | `admin` |
| **默认密码** | `CloudLensAdmin2024!` |

**重要**：登录后请在 **设置** 中修改密码。

---

## 忘记密码时：在服务器上重置

用户数据保存在服务器上的 `~/.cloudlens/users.json`（在 Docker 中为 `/root/.cloudlens/users.json`）。需在 **EC2 实例上** 执行以下任一方式。

### 方式一：SSH 进实例后执行 Python 一行命令（推荐）

```bash
# 1. SSH 登录香港实例（替换为你的密钥和 IP）
ssh -i ~/.ssh/cloudlens-key ec2-user@<实例公网IP>

# 2. 在容器内执行：创建/重置用户 admin，密码设为 CloudLensAdmin2024!
docker exec cloudlens-backend python3 -c "
import hashlib, json
from pathlib import Path
from datetime import datetime
p = Path('/root/.cloudlens/users.json')
p.parent.mkdir(parents=True, exist_ok=True)
users = json.loads(p.read_text()) if p.exists() else {}
pw = 'CloudLensAdmin2024!'
users['admin'] = {
    'username': 'admin',
    'password_hash': hashlib.sha256(pw.encode()).hexdigest(),
    'email': None,
    'role': 'admin',
    'created_at': users.get('admin',{}).get('created_at', datetime.now().isoformat()),
    'last_login': None,
    'enabled': True,
}
p.write_text(json.dumps(users, ensure_ascii=False, indent=2))
print('已重置用户 admin，密码: CloudLensAdmin2024!')
"
```

若要将密码改为自定义值，把上面两处 `CloudLensAdmin2024!` 改成你的新密码即可。

### 方式二：使用项目内脚本（在容器内能访问到脚本时）

若容器内存在 `/app/scripts/reset_admin_password.py`（或该脚本已复制进容器），可执行：

```bash
docker exec -it cloudlens-backend python3 /app/scripts/reset_admin_password.py admin 你的新密码
```

不传参数时默认用户名为 `admin`，默认密码为 `CloudLensAdmin2024!`。
