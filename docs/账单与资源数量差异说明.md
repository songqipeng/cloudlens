# 为什么「资源」很少但账单金额很高？

## 结论先说

- **「资源」页**里展示的是：当前通过 OpenAPI 拉取的**部分实例型资源**（如 ECS、RDS、Redis 等），数量可能很少。
- **账单**里统计的是：该账号下**所有阿里云产品**产生的费用（ECS、RDS、OSS、流量、SLB、EIP、CDN、域名、短信等）。
- 所以**资源数量少、去年账单却接近 10 万**是正常现象：大部分费用往往来自「不在资源列表里的产品」。

## 常见高费用来源（不在「资源」列表里）

| 类型 | 说明 |
|------|------|
| 对象存储 OSS | 存储费 + 外网下行流量、请求次数等 |
| 按量付费 ECS / RDS | 未在「资源」里展示的按量实例、抢占式实例 |
| 负载均衡 SLB、EIP、NAT 网关 | 按流量/按规格计费 |
| CDN、视频点播 | 流量与转码费用 |
| 数据库（PolarDB、MongoDB 等） | 若未在资源模块接入，不会出现在「资源」里 |
| 短信、邮件、域名、SSL 等 | 按次/按量计费 |

因此：**看「资源」数量无法反推账单金额**，要看账单按产品的构成。

## 如何查看 ydhl 去年近 10 万花在哪

### 1. 在系统里看「成本构成」（当月）

- 登录 CloudLens → **成本分析** → 选账号 **ydhl**。
- **成本构成**来自 BSS 账单按产品聚合，可以看到当月各产品（产品名/代码）及金额，判断主要花费在哪些产品。

### 2. 在本地看「去年全年」按产品汇总（推荐）

- 已在后端提供接口，**在本地浏览器或终端即可查看**，无需新功能、无需跑脚本环境：
  - **浏览器**：登录 CloudLens 后，在地址栏打开（把 `ydhl`、`2025` 换成你要的账号和年份）：
    ```text
    https://cloudlens.songqipeng.com/api/cost/yearly-by-product?account=ydhl&year=2025
    ```
  - **终端**（本机执行即可）：
    ```bash
    curl -s "https://cloudlens.songqipeng.com/api/cost/yearly-by-product?account=ydhl&year=2025"
    ```
- 返回 JSON：`year`、`total`（年度总成本）、`by_product`（产品列表，含 `product_code`、`product_name`、`amount`，按金额从高到低）。
- 数据来源：远端 MySQL 的 `bill_items`（需已同步该账号对应年份的账单）。若返回 `total: 0` 且 `message` 提示无数据，请先在控制台或 CLI 同步 2025 年账单后再查。

### 3. 在阿里云控制台核对

- 阿里云控制台 → **费用中心** → **账单详情** → 按账期、按产品/计费项查看，与上面结果交叉验证。

## 可选：本地脚本

- 若你更习惯在**能连 MySQL 的本机环境**跑脚本，可用：`scripts/yearly_cost_by_product.py`（用法见脚本内注释）。依赖：CloudLens 配置、MySQL 中 `bill_items` 已有该账号对应年份数据。
